# WalletChan Mascot

The character system, authoring experiment, assets, and implementation guidance
live in private [walletchan/mascot](https://github.com/walletchan/mascot).
Read its [mascot system document](https://github.com/walletchan/mascot/blob/main/_docs/MASCOT.md)
for semantic states, reduced motion, and Rive authoring.

The extension retains its packaged unlock-screen raster pilot and product assets.
The website and shared brand assets also remain here; builds do not fetch the
private mascot repository. See [STYLING.md](./STYLING.md) for local UI conventions.
